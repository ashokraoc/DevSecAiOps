## 1. Interview Questions

**Q1. What is Ansible?**

Ansible is an open-source, agentless IT automation tool used for configuration management, application deployment, infrastructure provisioning, and orchestration.

**Q2. What does agentless mean in Ansible?**

Agentless means that an additional Ansible agent does not need to be installed on each managed node.

**Q3. Which protocol does Ansible use to connect to Linux servers?**

Ansible typically uses SSH to connect to Linux managed nodes.

**Q4. What is a playbook in Ansible?**

A playbook is a YAML file that defines the tasks Ansible should execute on managed nodes.

**Q5. What is an inventory file?**

An inventory file contains the hostnames or IP addresses of the systems that Ansible manages.

**Q6. What is idempotency?**

Idempotency means that repeatedly applying an operation produces the same desired state without making unnecessary changes.
